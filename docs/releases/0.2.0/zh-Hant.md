Aphelion 的第一個公開版本。

- **啟動**：原版、Fabric、Quilt、Forge、NeoForge；每個實例自成一個資料夾；自動選擇並下載所需的 Java；崩潰時自動分析原因。
- **只用官方來源下載**：大檔案分段平行下載、斷線續傳；自動挑選最快的 CDN 節點；電腦上其他遊戲目錄已有的相同檔案直接重用。設定 › 下載與網路可以檢查每個官方伺服器的連線狀況。
- **帳戶**：離線、微軟、外置登入（authlib-injector）；權杖以 Windows DPAPI 加密保存。
- **內容**：Modrinth 搜尋與安裝（含相依項目）、更新檢查、整合包匯入與匯出。
- **安裝、可攜與更新**：免系統管理員權限安裝；一鍵切換標準／可攜模式並安全搬移資料；之後的版本可以直接在程式內更新（簽章驗證）。
- **介面**：任務控制台風格，繁體中文、簡體中文、英文，深色與淺色主題，最小 900 × 600 視窗。
