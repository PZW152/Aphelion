Aphelion 的第一个公开版本。

- **启动**：原版、Fabric、Quilt、Forge、NeoForge；每个实例自成一个文件夹；自动选择并下载所需的 Java；崩溃时自动分析原因。
- **只用官方来源下载**：大文件分段并行下载、断线续传；自动挑选最快的 CDN 节点；电脑上其他游戏目录已有的相同文件直接复用。设置 › 下载与网络可以检查每个官方服务器的连接状况。
- **账户**：离线、微软、外置登录（authlib-injector）；令牌以 Windows DPAPI 加密保存。
- **内容**：Modrinth 搜索与安装（含依赖项）、更新检查、整合包导入与导出。
- **安装、可携与更新**：无需管理员权限安装；一键切换标准／可携模式并安全搬移数据；之后的版本可以直接在程序内更新（签名验证）。
- **界面**：任务控制台风格，繁体中文、简体中文、英文，深色与浅色主题，最小 900 × 600 窗口。
