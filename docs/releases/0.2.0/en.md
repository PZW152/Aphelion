The first public release of Aphelion.

- **Launch**: vanilla, Fabric, Quilt, Forge and NeoForge; every instance is one self-contained folder; the right Java is chosen and downloaded automatically; crashes are diagnosed.
- **Official sources only**: large files in parallel ranges with resume, the fastest CDN edge picked automatically, identical files already on the PC reused. Settings › Download includes a connection check for every official server.
- **Accounts**: offline, Microsoft, and authlib-injector servers; tokens encrypted with Windows DPAPI.
- **Content**: Modrinth search and install with dependencies, update checks, modpack import and export.
- **Install, portable, updates**: per-user install without administrator rights; one-click switch between standard and portable mode with safe data moves; later versions update in place from inside the app (signature-verified).
- **Interface**: a mission-control console in Traditional Chinese, Simplified Chinese and English, dark and light themes, works from a 900 × 600 window.
